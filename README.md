# Haya2 — portfolio showcase

Live website: https://underthehaik.github.io/haya2/

A static export of the existing WordPress/WooCommerce storefront for sharing in a portfolio. Products and information pages are browsable; live checkout, accounts, dynamic server filtering and contact transmission require WordPress hosting and are not provided by GitHub Pages. No database, orders or admin credentials are included.

The complete original local project is in [shop/](shop/README.md). Run its setup and start scripts from that folder; generated runtime stays in the ignored root work directory.

GitHub Pages serves the exported gh-pages branch.
